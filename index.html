    How to create one

    1. Open github.com/settings/personal-access-tokens/new (fine-grained token).
    2. Repository access: Only select repositories → nfl-bot.
    3. Repository permissions: Actions: Read and write, Contents: Read-only (Metadata: Read-only is added automatically).
    4. Generate, copy, paste here, tap Save, then Test.
